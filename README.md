# IMDb Data Workflow

This project automates data cleaning, indicator calculation,
and HTML dashboard generation for an IMDb Top 1000 dataset.

## Dataset

https://www.kaggle.com/datasets/harshitshankhdhar/imdb-dataset-of-top-1000-movies-and-tv-shows

## Questions

1. Which genres have high gross earnings relative to their IMDb ratings?
2. How does average movie runtime change over the years?
3. Which genres have a higher proportion of high-grossing movies?

High-grossing movies are defined as movies with Gross at or above
the 75th percentile of movies with available Gross data.
